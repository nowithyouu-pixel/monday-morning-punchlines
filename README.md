One original Monday-morning joke, delivered by a tiny deterministic Python program — it writes a single fresh punchline to `/output/entry.txt`. The joke puts Monday on a performance review (shows up uninvited, no snacks, zero stars) and lets it book its own follow-up meeting.

## Run it

```sh
python3 main.py
```
